# Pricing API Reference

**Base URL:** `http://localhost:8080/api/v1`
**Content-Type:** `application/json`
**Management URL:** `http://localhost:8081/actuator`

---

## Overview

The ePricing API is a REST HTTP API for loan pricing calculation. All endpoints accept and return JSON. Error responses follow a consistent structure.

---

## Authentication

> **Status: Not Implemented.** Authentication/authorization is not in scope for this version. All endpoints are publicly accessible. In production, add JWT Bearer token validation.

---

## Common Response Headers

| Header | Description |
|---|---|
| `X-Request-ID` | Unique request identifier (set or generated by `MDCFilter`) |
| `Content-Type` | Always `application/json` |

## Endpoints

### 1. POST /pricing — Calculate Loan Pricing

Creates a new loan pricing record by computing the interest rate, EMI, risk category, and eligibility.

```
POST /api/v1/pricing
Content-Type: application/json
```

#### Request Body

| Field | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `customer_id` | `string` | ✅ | Pattern: `CUST[0-9]{6,10}` | Customer identifier |
| `product_type` | `string` | ✅ | Non-blank | Loan product type |
| `loan_amount` | `number` | ✅ | Positive, ≤ 100,000,000 | Requested loan amount (INR) |
| `loan_tenure_months` | `integer` | ✅ | 12–360 | Repayment period in months |
| `credit_score` | `integer` | ❌ | 300–900 | CIBIL credit score |
| `annual_income` | `number` | ❌ | Positive | Annual income (INR) |
| `loan_purpose` | `string` | ❌ | Max 200 characters | Purpose of the loan |

**Valid product_type values:**
- `HOME_LOAN`
- `PERSONAL_LOAN`
- `AUTO_LOAN`
- `BUSINESS_LOAN`
- `EDUCATION_LOAN`

**Example Request:**
```json
{
  "customer_id": "CUST001234",
  "product_type": "HOME_LOAN",
  "loan_amount": 5000000.00,
  "loan_tenure_months": 240,
  "credit_score": 780,
  "annual_income": 2400000.00
}
```

**Success Response — `201 Created`:**
```json
{
  "request_id": 101,
  "customer_id": "CUST001234",
  "product_type": "HOME_LOAN",
  "loan_amount": 5000000.00,
  "loan_tenure_months": 240,
  "interest_rate_pa": 8.00,
  "emi_amount": 41822.00,
  "total_payable_amount": 10037280.00,
  "total_interest_payable": 5037280.00,
  "risk_category": "LOW_MEDIUM",
  "status": "CALCULATED",
  "trace_id": "abc123def456789",
  "processed_at": "2024-01-15T10:30:00.000+05:30"
}
```

**Error Responses:**

`400 Bad Request` — Validation failure:
```json
{
  "error_code": "PRICING_VALIDATION_FAILED",
  "message": "Request validation failed: {customer_id=must match CUST[0-9]{6,10}}",
  "http_status": 400,
  "timestamp": "2024-01-15T10:30:00.000+05:30"
}
```

`422 Unprocessable Entity` — Business rule violation:
```json
{
  "error_code": "INSUFFICIENT_CREDIT_SCORE",
  "message": "Credit score 620 is below minimum required 650",
  "http_status": 422,
  "timestamp": "2024-01-15T10:30:00.000+05:30",
  "customer_id": "CUST001234"
}
```

### 2. GET /pricing — Get Pricing History

Returns pricing history for a customer, or the 10 most-recent records.

```
GET /api/v1/pricing
GET /api/v1/pricing?customerId=CUST001234
```

#### Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `customerId` | `string` | ❌ | Filter by customer ID; returns top 10 if omitted |

**Success Response — `200 OK`:** Array of `PricingResponseDto`

```json
[
  {
    "request_id": 1,
    "customer_id": "CUST001234",
    "product_type": "HOME_LOAN",
    "loan_amount": 5000000.00,
    "loan_tenure_months": 240,
    "interest_rate_pa": 8.50,
    "emi_amount": 43391.16,
    "status": "CALCULATED",
    "processed_at": "2024-01-10T09:15:00.000+05:30"
  }
]
```

---

### 3. GET /pricing/{id} — Get Pricing by ID

Retrieves a single pricing record by database ID.

```
GET /api/v1/pricing/42
```

#### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| `id` | `long` | Pricing record ID |

**Success Response — `200 OK`:** Single `PricingResponseDto`

**Error Response — `404 Not Found`:**
```json
{
  "error_code": "PRICING_NOT_FOUND",
  "message": "Pricing record not found for ID: 42",
  "http_status": 404,
  "timestamp": "2024-01-15T10:30:00.000+05:30"
}
```

---

### 4. GET /health — Application Health

Returns business-level health status.

```
GET /api/v1/health
```

**Success Response — `200 OK`:**
```json
{
  "status": "UP",
  "application": "epricing-service",
  "active_pricing_requests": 2
}
```

## Error Code Reference

| Error Code | HTTP Status | Description |
|---|---|---|
| `PRICING_VALIDATION_FAILED` | 400 | Request DTO validation failure |
| `INSUFFICIENT_CREDIT_SCORE` | 422 | Credit score below minimum (650) |
| `LOAN_AMOUNT_EXCEEDS_ELIGIBILITY` | 422 | Loan > 60% of annual income |
| `PRICING_NOT_FOUND` | 404 | No record for the given ID |
| `PRICING_CALCULATION_ERROR` | 500 | Unexpected mathematical error |
| `INTERNAL_ERROR` | 500 | Unhandled exception |

## Example Requests (cURL)

```bash
# Calculate pricing for a home loan
curl -X POST http://localhost:8080/api/v1/pricing \
  -H "Content-Type: application/json" \
  -H "X-Request-ID: my-req-001" \
  -d '{
    "customer_id": "CUST001234",
    "product_type": "HOME_LOAN",
    "loan_amount": 5000000,
    "loan_tenure_months": 240,
    "credit_score": 780,
    "annual_income": 2400000
  }'

# Get history for customer
curl "http://localhost:8080/api/v1/pricing?customerId=CUST001234"

# Get by ID
curl "http://localhost:8080/api/v1/pricing/1"

# Health check
curl "http://localhost:8080/api/v1/health"

# Actuator health
curl "http://localhost:8081/actuator/health"

# Prometheus metrics
curl "http://localhost:8081/actuator/prometheus"
```
